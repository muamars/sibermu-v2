# LANDING-PAGE-STRUCTURE.md — SiberMu 2026

## 1. Tujuan Halaman

Landing page ini dirancang sebagai satu halaman terpadu yang memperkenalkan:

- kehidupan kemahasiswaan di Universitas Siber Muhammadiyah,
- organisasi dan komunitas mahasiswa,
- prestasi mahasiswa,
- layanan mahasiswa,
- kegiatan Al-Islam dan Kemuhammadiyahan,
- nilai Islam Berkemajuan.

Arah komunikasi:

> **Modern, dekat, hangat, akademik, dan Islami.**

Landing page tidak diposisikan sebagai portal informasi yang berat, tetapi sebagai halaman yang membuat pengunjung merasa:

> **“Di SiberMu, saya bisa belajar, bertumbuh, terhubung, dan memberi dampak.”**

# 23. Tone of Voice

Copywriting harus terasa:

```txt
ringkas
hangat
optimis
berisi
tidak terlalu formal
tidak terlalu marketing
tidak menggurui
```

Gunakan pola:

```txt
Headline pendek
+
1–2 kalimat penjelasan
+
CTA
```

Hindari headline seperti:

```txt
Selamat Datang di Website Kemahasiswaan Universitas Siber Muhammadiyah
```

Lebih baik:

```txt
Lebih dari sekadar kuliah.
```

Hindari:

```txt
Kami menyediakan berbagai macam layanan mahasiswa yang dapat digunakan...
```

Lebih baik:

```txt
Ada yang mendukungmu di setiap perjalanan.
```

# 24. Core Copywriting Theme

Seluruh halaman dapat disatukan dengan tiga kata:

```txt
Belajar
Bertumbuh
Berdampak
```

Narasi halaman:

```txt
BELAJAR
SiberMu memberi akses pendidikan yang fleksibel dan relevan.

BERTUMBUH
Mahasiswa menemukan komunitas, pengalaman, dan ruang pengembangan diri.

BERDAMPAK
Ilmu dan nilai dibawa menjadi karya serta manfaat bagi masyarakat.
```

Kemahasiswaan berada pada bagian:

```txt
BERTUMBUH
```

AIK menjadi fondasi:

```txt
NILAI
```

Prestasi dan kontribusi berada pada:

```txt
BERDAMPAK
```

Dengan begitu seluruh landing page terasa sebagai satu cerita, bukan kumpulan section yang berdiri sendiri.
